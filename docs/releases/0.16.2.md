## 修复接口响应处理

远程删除接口尚未加载时，DSH 会返回纯文本 `404 not found`。此前客户端直接按 JSON 解析，导致确认框显示 `Unexpected token 'o'`。现在统一读取并校验响应，显示接口未加载及重新加载插件的提示；登录拒绝、服务异常和无效响应也有明确提示。

保留宿主返回的结构化 Git 错误，避免把“目标引用不存在”等实际业务错误误报为接口未加载。失败后保留确认框，不自动重试删除请求。

客户端回归改用真实 HTTP Response，覆盖纯文本 404、401、HTML 502、无效成功响应、结构化 404 以及 GET 认证失败。

## 已更新客户端但接口未加载时

在 DSH 的“插件”页关闭再开启“Git 工作区”，触发宿主代码重新加载，然后重新打开 Git 面板操作。仅刷新网页会更新客户端文件，不保证加载已修改的宿主路由；也可重启 DSH。
