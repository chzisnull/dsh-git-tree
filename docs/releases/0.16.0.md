## 新增

- 远程分支按远端分组展示，支持展开收起、查看历史和复制完整名称；引用树按符号引用元数据排除 `origin/HEAD` 等别名。
- “所有分支”历史包含远程独有提交，并显示远程引用标记；新增加载、失败、未配置远端、尚无已获取分支及引用消失提示。
- 远程分支菜单支持删除服务器上的目标分支：输入完整名称确认，绑定快照提交的 lease，远端更新、分支保护或权限拒绝时不会删除。
- 本地分支新增独立的强制删除入口，可删除未合并分支；默认删除仍使用安全模式，当前分支或其他 worktree 占用的分支不能删除。

## 修复

- 放弃更改和删除文件使用精确字面路径，避免特殊文件名匹配到其他文件；统一子目录工作区中的仓库根路径基准。
- 为 Git 命令建立实际运行期限，并保留标准输出中的失败诊断，正确显示真实合并冲突。
- 引用树、diff、历史、提交详情及 AI 草稿忽略旧仓库或过期请求的结果；修复重复选择时加载状态无法结束的问题。
- 手动刷新和前台轮询更新选中 diff，涵盖文件仍为修改状态但内容已变化的场景；远端列表和作者信息变化会更新界面。
- 修复标签右键回调；删除成功后刷新历史标记并正确区分同名本地与远程分支。
- AI 冲突预览绑定仓库、路径和原始文件内容，应用前拒绝过期预览，保护预览期间的人工修改。
- 支持 Git 可变长度冲突标记；提交文件列表保留中文、换行、制表符、反斜杠和重命名路径。

## 验证与更新

新增客户端行为回归和真实隔离 Git/bare remote 集成测试，覆盖删除竞态、保护 hook、复杂引用映射和部分成功结果。构建产物及中英文文档同步更新。

此版本包含宿主端改动，更新插件后请重启 DSH。远程树表示本地获取快照；现有获取操作仍更新当前上游对应的远端，不新增定时联网或获取全部远端。
