# 用快捷键打开面板

面板原先只能从侧栏图标点开，反复开合要来回移鼠标。用户要求「添加快捷键能够快速打开它」，键位定为 `⇧⌘V`，同时要在界面上给用户指引，并且明确不能因此影响 DSH 启动。

DSH 0.2.1 起自带客户端快捷键服务 `ctx.shortcuts`（`@deepseek-ai/dsh-client-shortcuts`）：插件注册的命令会进入应用自己的「键盘快捷键」页（`⌘/`），可搜索、可改键、可恢复默认，匹配与优先级也由应用统一仲裁。自己监听 `keydown` 既会与输入框里的系统组合冲突，也无法被用户改键，因此走服务。注册校验与派发细节记在 `docs/dsh-plugin-api.md` §6.5（含 `app.asar` 里的 file:line 引用）。

## 决定

- **通过服务注册，不自己监听键盘**。命令 id 为 `panel.git-tree.toggle`，标签「打开 Git 面板 / Open Git panel」，别名带 `git`、`git panel`、`source control`、`scm`。
- **默认键位**：`⇧⌘V`（macOS）与 `Ctrl+Shift+V`（Windows），桌面端与网页端两个 shell 都声明。**Linux 不声明默认值**：服务把 `primary + KeyV` 判为保留组合，声明会让注册抛错；Linux 用户可在快捷键页自行绑定。
- **语义是切换**：面板正是当前主面板时按一下回到对话，否则打开面板。切仓库、切视图不受影响，侧栏图标行为不变。
- **快捷键服务是可选依赖**：`inject` 保持 `['slots', 'locale']` 不变，改用 `ctx.inject(['shortcuts'], …)`（子 fiber 等到服务就绪）并配合 `ctx.get('shortcuts')`。DSH 没有这个服务时面板照常加载，只是没有快捷键。
- **注册被拒只降级**：保留组合、与其他命令默认值重叠、id 重复都由服务抛错；一律 `try/catch` 记为「没有快捷键」，绝不冒泡到插件加载层。
- **输入框里也响应**：`regions` 取 `page`、`editable`、`terminal`。最初想按「网页端不抢输入框」排除 `editable`，沙盒实测发现一个反例：切换回对话时焦点会落进输入框，于是「再按一次重新打开」在网页端失灵。桌面端本来就会把已注册组合排在输入框之前，这里保持一致。代价是网页端输入框里的「粘贴为纯文本」（`⌘⇧V`）让位；介意的人在快捷键页给这条命令换一个组合即可。
- **面板自己的浮层按住快捷键**：确认框、命名框、AI 冲突预览或右键菜单开着时，命令返回服务的 `blocked`——按键被消费但什么都不做（`handled` 会执行动作，`pass` 会让按键落到底层被解释成粘贴）。桌面端优先级高于浮层，不这样做一次误触就会把面板连同未保存的 AI 预览一起关掉。
- **提示分三层**：工具栏右侧键帽徽标（可点，等同切换）、diff 空态的一行说明、以及 DSH 自己的快捷键页。徽标键帽取自实时目录，用户在设置里改键后立即跟着变；命令未绑定时徽标与空态提示都不渲染，不留死控件。
- **不做**：全局 keydown 监听、插件自己的快捷键配置文件、多套快捷键、面板内的快捷键列表页。

## 结果

- 新增 `src/client/shortcut.ts`（服务可选访问、命令注册、切换语义、浮层挂起、键帽读取）与 `index.tsx` 里的接线。
- `TopBar` 增加键帽徽标，`DiffView` 空态增加一行提示，`Workspace` 在浮层打开时挂起快捷键。
- 新增 10 条测试（boot 契约 8 条：默认值形状、开合语义、注册被拒降级、无服务降级、键帽读取与未绑定、浮层挂起、只关自己的面板、服务非硬依赖；UI 契约 2 条）。
- 已知取舍：绑定后 `⇧⌘V` 不再触发输入框的系统「粘贴为纯文本」（桌面端与网页端一致）。介意的人在「设置 → 键盘快捷键」里改一个组合即可，无需重装。
